# YouTube Creative Suite 🎬

Esta suite reúne todas as ferramentas necessárias para transformar uma ideia ou documento técnico em um conteúdo de alta performance para o YouTube, focado em retenção, SEO e autoridade.

## Skills Integradas

1.  **youtube-pesquisa**: Deep-dive para encontrar ângulos e dados de autoridade.
2.  **youtube-roteiro**: Transforma conteúdo técnico em roteiros dinâmicos.
3.  **youtube-ganchos**: Cria hooks irresistíveis (aberturas de 30s).
4.  **youtube-titulos**: Otimização Ph.D. de CTR e SEO para títulos.
5.  **youtube-tags**: Geração de metadados focados em search intent.
6.  **youtube-descricoes**: Criação de descrições magnéticas com capítulos e CTAs.
7.  **youtube-step-extractor**: Extração de tutoriais passo-a-passo.
8.  **youtube-thumbnail-downloader**: Gestão de referências visuais.

## Como Usar
Acione esta suite sempre que o objetivo for produzir conteúdo para redes sociais, especificamente YouTube. O Maestro delegará para a sub-skill correta dependendo da etapa do funil de produção em que você se encontra.
